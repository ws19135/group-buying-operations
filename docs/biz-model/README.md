## 先看這三個結論

1. **三種模式不是三選一**：是同一檔上可同時存在的收益腿（公司對品牌一條、公司對每位團主一條）。模式由檔期的合約條件推導，不放單選欄位（02 §2）。
2. **GMV 不是公司收入**：公司收入只認服務費／分潤；貢獻利潤＝公司營業收入 − 公司負擔的團主分潤 − 直接變動成本（04 §1、§2）。
3. **最大的技術缺口是退款事件日期**：沒有它，跨期退款更正與「退款當期」口徑都做不出來（08 G-02）。
